# Source review only: do not push or run
Only branch qa/pr90-synthetic-payment-ui, never master. Exact public PR90 commit and tree only; no private overlay. The workflow does not boot an API, uses no DB/services, contains no real payment actions or credentials. Git checkout does not persist credentials.

Tool lock contains cross-checked provisional SRI pins, not locally authenticated registry responses. The workflow must verify package names, exact versions, official registry tarball URLs, SHA-512, dependencies and platform/bin metadata against exact official npm responses before npm ci. A mismatch, inaccessible registry or unexpected dependency fails closed. Install lifecycle scripts stay disabled. Playwright's standard Chromium/system dependency setup is explicitly in the acquisition phase only. No cache reuse or lock fallback.

Only a bounded, redacted synthetic pass/fail summary is retained for seven days. The job never uploads screenshots, the browser output tree, arbitrary errors, checkout files or environment data. Absence of a browser report signifies an incomplete run and does not produce a misleading artifact.

Isolation design: freshly fetch exact PR90 frozen lock dependencies to a private runner temp store with no lifecycle scripts; no reuse/shared caches. New user+PID+network namespace, distinct network inode, only loopback and no non-loopback IPv4/IPv6 routes; no privilege/security-setting fallback. Empty environment except explicit allowlist. Offline filtered frozen install (root, web and workspace dependencies), shared/web builds only, no Prisma or database build, no lifecycle install scripts, no VITE_API_URL and explicit same-origin API proxy mode. Fresh dist and exact checkout/pinned inputs are required. Build writes a same-job file-size/SHA-256 receipt and prepare verifies/copies the exact file set. This receipt is not a remote attestation and accepts no external build artifact. Static preview exposes exact synthetic document routes and files, no API/proxy; checks reject API and write methods before browser starts. Browser harness only receives fixtures from request interception inside the OS boundary.

Open before publication: exact store fetch/filtered offline resolution, Ubuntu namespace viability, and Playwright browsing are **untested**, including app assets/navigation and completeness of fixture assumptions. Any denied namespace/install, missing build output, lock mismatch or missing receipt, or unknown browser traffic must fail, not skip. Supplemental synthetic UI QA only, not production or financial/migration acceptance.
