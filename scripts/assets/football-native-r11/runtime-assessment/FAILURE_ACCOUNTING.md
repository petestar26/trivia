## Environment and harness errors — not source defects

- **Sandbox Blender startup:** exit139 before Python, in Metal device detection (`ARCH_CACHE_LINE_SIZE` warning/backtrace). Successful read-only runs used explicitly authorized unsandboxed CLI, `--disable-autoexec` and `--python-exit-code 1`; no global app permissions changed. Retained:`native-validation-baseline.log`, `native-validation-baseline-sandbox.crash.txt`, successful`native-validation-baseline-unsandboxed.log`.
- **Old local clone:** upload-pack could not read unrelated object`f2fc75d0f0e9b7865f4c67e758b7b9767d536585`; exit128. Root used a fresh verified GitHub clone, without rewriting the old repository. Evidence:`../validation/local-clone-attempt.json`.
- **Scratch prerequisites/serialization:** NumPy unavailable; validator replaced with stdlib arrays. `py_compile` could not write the system cache; direct`compile()`passed. Sock inventory JSON initially failed on a non-JSON`bpy_prop_array`. These are tool errors, not failed geometry. Logs/notes remain in`boot-reference/iterations/validation-numpy-unavailable.log`, `native-validation-syntax.json`, `native-sock-attribute-inventory.log`.
- **Boot sampling context:** initial sampler left the opposite foot below ground, adding an unintended correction. That run remains in`boot-reference/iterations/unconstrained-other-foot.*`. Corrected16samples SHA`92a0dad2f3566bc8c1f06d2b80d63f364f97bde26f87b3d071a2048f44d64a1c`; exact241jog-context output SHA`217aa045a5b06b725eebe7cd3eb76a7a1be514091dcb3c5f8f21b8f1b57cad5d`.
