The adapter does not move root, pelvis or legs, advance clocks, publish events or choose outcomes. Keeper wrists retain their solved targets; offsets are zero at the existing 0.45-second contact. Reduced motion is still. Existing authored clip source/export hashes remain unchanged.

`sampleReviewFinishingSequence` supplies a continuous 7.65-second diagnostic journey: acceleration to 1.8 seconds, jog to 3.0, moving quarter-turn to 4.4, smooth braking to 6.2, idle to 6.8, then the existing 0.85-second kick. Actual released-match playback is verified separately.

[continuous-player-lod.ts](../../apps/web/src/components/football/engine/continuous-player-lod.ts) builds reduced geometry once at load time. It partitions clusters by component, side, material, exact influence-bone set and UV region, retaining boundary/neck vertices and fine hand/finger cells. Unsafe clusters remain verbatim through bounded retries, with a complete clone fallback if the topology audit fails. It retains all eight morph channels and metadata, normalizes weights, recomputes ordinary unit normals, and preserves the accepted neck data verbatim. It never removes arbitrary faces to manufacture a reduced count.
