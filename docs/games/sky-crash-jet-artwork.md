# Sky Crash jet artwork

Replaces the propeller aircraft in the flight scene and available Sky Crash game cards with a twin-engine business jet. Flight positions, departure triggers, server results and reduced-motion behavior are unchanged. The failed-image fallback also uses a swept-wing jet silhouette.

Runtime asset: `apps/web/public/images/sky-crash/jet-v1.webp` (1024 × 512, alpha transparency, approximately 83 KiB). The versioned URL avoids reusing the cached propeller image. The original aircraft asset remains retained.

Created using the built-in image generator with the previous aircraft as a style/orientation reference. Exported as WebP for runtime use; no added background or hand-painted retouching.
