# One review actor native jog adapter

The existing home outfield slot1 (shirt2) adopts the verified native V5 geometry and semantic V3 jog controls. Other actors retain their existing assets and motion. The native asset loader validates the complete set before adoption; rejection retains the complete legacy continuous player and its motion. This remains a draft review candidate, without roster expansion, rollout, deployment, rule, outcome or clock changes.

`native-jog-controls.json` retains only normative semantic controls and their explicit per-phase Hermite tangents from evidence `motion/v3/jog-controls.json` SHA-256 `f5d4b6bb8911693eccd798d83fff2c0be5cdca3c74038f83902b0925736c8422`. The authored pelvis position and quaternions are absolute canonical-local values. Quaternion components and root-space pole directions are normalized after Hermite sampling. The adapter uses the existing distance/stride phase; native seconds/cadence do not advance a second playback clock. No native root, solved leg, foot, toe, ball or event tracks are adopted.

Reproduce the compact export with `node scripts/assets/export-football-native-jog.mjs /path/to/verified/motion/v3/jog-controls.json --check`. Omit `--check` to write it. The exporter verifies the original input hash, which rejects another take or an accidentally edited evidence source. Source geometry/rig provenance remains in the original retained evidence and native geometry manifest.

The normal base pose, normal pose transition, accepted review posture and final `plantRunFeet` execute first. The adapter captures that original baseline pose and complete final world ankle rotations/positions plus toe local rotations. Only then does it blend visual pelvis/torso controls and solve the same ankle targets with authored knee directions. It restores full foot world quaternions and original toe locals. It never calls `plantRunFeet` again or changes the held `RunPlant` state. This order matters: the original plant solver reads hips world yaw when deciding pivot/release behavior. Applying the visual pelvis first would silently alter that plan.

Acceleration/braking attenuates between absolute0.35 and3m/s²; turn effort attenuates between absolute0.04 and0.35. A0.12-second exponential response controls entry and exit; dt0 does not advance history. Native pelvis/leg solving is confined to run. Other actions retain their existing poses, targets and clocks; accepted outgoing torso/arm transitions carry the previous actual native contribution. For unreachable ankle targets the visual pelvis contribution is attenuated by a bounded18-step feasibility search, or the exact original pose is retained. No target relocation or bone stretching is permitted.

Absolute native free-arm targets feed the accepted review arm transition owner before application. The owner therefore retains actual applied native locals for interruption rather than stale legacy jog targets. Native finger locals apply after legacy hand targets and before the pool's existing temporal filter. Native torso outgoing deltas are committed to the same posture owner. Baseline snapshots used for the next base-pose transition exclude new visual pelvis/leg solving, preserving original contact planning across actions. Teleports, teams, rewind, long suspension, reduced motion and disposal clear private native state and sampled/baseline buffers.
