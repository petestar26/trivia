# Original Football animation authoring

The renderer uses 14 original clips: run, acceleration, planted turn, idle, kick, keeper ready, keeper dive (including launch, landing and recovery), five celebration variants, dejected, and a run swing control curve. These are deliberately selected anatomical key poses and independently drawn IK control curves. No imported animation, motion capture, downloaded asset, or samples of the former procedural pose functions were used.

`apps/web/src/components/football/engine/authored-motion-source.json` is the editable authoring source. It contains named pose intentions, joint rotations in degrees, pelvis positions, gesture controls and explicit control tangents. `scripts/assets/export-football-motion.mjs` constructs native Three quaternion/vector tracks. Monotone cubic handles between authored rotation keys become dense quaternion keys; extrema and closed cycle seams are retained. Constant channels have only endpoint keys. Run swing retains independently authored Hermite target handles so stride length can adapt while maintaining stance endpoint velocity.

Run `node scripts/assets/export-football-motion.mjs` to regenerate, or append `--check` to verify reproducibility. The exporter reads the authoring JSON rather than executing runtime poses. Generated copies are identical at `authored-motion-clips.json` and `apps/web/public/models/football/original-authored-motion.json`. Current source SHA-256 is `e0cb2855cf7c23e27da2e201c21edf50d24baa16ae0364171460b472f5d8d1fd`; the portable bundle is 269524 bytes. The bundle embeds source provenance and fixed contact markers.

`createAuthoredBodyClip` returns an independent native `AnimationClip` usable directly by Three's `AnimationMixer` on the actual rig. It removes virtual gesture-control tracks; those are sampled by `sampleAuthoredControl`. `applyAuthoredMotion` interpolates the same body tracks and blends posture, with explicit mirroring, amplitude and protected pelvis-translation options. Clips animate the original 19 body bones. The extended 49-bone rig's fingers use the separate gesture adapter.

Authored posture runs before the existing world sole, ball-contact and hand IK. Support pelvis translation remains governed by that solver; authored translations do not replace planted-foot corrections. Acceleration and planted-turn overlays use bounded weights. Kick remains at 0.3 seconds, keeper reveal at 0.45 seconds, recovery at 1.8 seconds and goal at 2.05 seconds. These markers describe the existing director schedule; clip playback does not publish events or decide outcomes.

Focused validation exercises the native mixer against an intentional source pose, independent rigs and frame-step histories, loop seams, mirroring, controller endpoints and tangents. Actual world foot and keeper reach probes cover both directions and dressed scales 0.96 and 1.04, and the unchanged strict stance/pivot/support tests remain applicable. This proves a reproducible original keyframed pipeline and the tested contact constraints. It does not constitute motion-capture provenance, physical-device acceptance or a claim that every pose has production-film realism.
