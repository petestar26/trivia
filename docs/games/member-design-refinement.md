# Salem member interface refinement

Direction: graphite and black-cherry surfaces, burgundy selection states, rose-gold primary actions, warm readable text, and restrained depth. Emerald marks available practice play; muted neutral badges mark unavailable or upcoming content. Game scenes retain their own functional colors.

The dashboard puts game discovery before secondary activity. A compact hero and three functional shortcuts lead to games, gifts and groups. The shared member shell, catalogue, gift shop and practice wallet use consistent surfaces and spacing. Mobile navigation provides five destinations and is omitted on game detail and message routes to preserve control space. Keyboard focus indicators, reduced-motion preferences and mobile safe areas are retained.

Reference research: Stake's public casino lobby exposes search and categorized discovery (https://stake.com/casino/home); Chess.com's play page uses task-based navigation (https://www.chess.com/play). These informed information hierarchy, not copied branding, assets or promotional mechanics. Duelbits did not provide readable content through the research tool and was not treated as verified visual evidence.

Scope: member shell and primary member pages; no gameplay, money movement, admin workflow or provider integration changes. Existing artwork is reused. The CSS is member-scoped and does not theme staff workspaces.

Validation: dashboard/gift/wallet interaction tests, mobile navigation tests, production typecheck/build and PWA checks. Signed-in hosted browser and physical-device visual acceptance remain outstanding; do not describe this as a complete pixel-level audit of every route.
